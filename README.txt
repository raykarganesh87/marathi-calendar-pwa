MARATHI PANCHANG CALENDAR MAKER (PWA)
=====================================
Upload every file in this folder to the ROOT of a GitHub repository, then:
Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
Your app opens at  https://<your-github-username>.github.io/<repository-name>/

Files: index.html (app), app.js, worker.js, engine.js (astronomy + festival rules), render.js (pages),
data.js, places.js, style.css, sw.js (offline cache), manifest.webmanifest, fonts/, icons/,
astronomy.browser.min.js (astronomy-engine, MIT licence), .nojekyll
Font: Noto Sans Devanagari (SIL Open Font License).
